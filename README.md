# Noor Technolab — Website

Official website of **Noor Technolab**, a new-age IT startup offering website development, mobile apps, custom software, AI solutions, UI/UX design and digital marketing.

## Pages
- `index.html` — Home
- `about.html` — About
- `services.html` — Services
- `work.html` — What We Build
- `industries.html` — Industries
- `blog.html` — Blog
- `contact.html` — Contact
- `careers.html` — Careers

Shared styles are in `assets/style.css`. The header, footer, menus and animations come from `assets/main.js`.

## Edit contact details
Open `assets/main.js` and update the `SITE` block at the top (email, phone, WhatsApp, address, social links).

## Run locally
Plain HTML, CSS and JavaScript — no build step. Open `index.html` in a browser, or serve the folder:

```bash
npx http-server -p 8080
```
